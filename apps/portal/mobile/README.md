# Portal mobile

Espaço reservado ao aplicativo móvel do portal do Miraj of Icarus. Este módulo
deverá oferecer recursos de conta e comunidade consumindo os mesmos contratos
públicos da API, sem incorporar responsabilidades do cliente do jogo.

## Limites do módulo

- autenticação e gestão da conta;
- consulta de servidores, personagens e releases;
- recursos futuros de comunidade e notificações;
- nenhuma regra de domínio duplicada no aplicativo.

## Desenvolvimento

Ainda não há runtime, dependências ou comandos de build definidos nesta pasta.
Quando a implementação começar, este README deverá registrar a stack escolhida,
requisitos, variáveis de ambiente, execução local, testes e publicação nas
lojas.

Tokens móveis deverão usar armazenamento seguro da plataforma. Segredos de
serviço nunca devem ser incorporados ao aplicativo.
